# 1. 非类型模板参数

**1. 浮点数、类对象以及字符串是不允许作为非类型模板参数的。 **

**2. 非类型的模板参数必须在编译期就能确认结果。**

```c++
#include <iostream>
using namespace std;

template<class T, size_t n>
struct Array
{
	T* _data[n];
};

int main()
{
	Array<int, 10> arr1;
	Array<int, 102> arr2;

	return 0;
}
```

**C++里面的 array。固定大小的数组。**

# 2. 模板的特化

```c++
#include <iostream>
using namespace std;

template<class T>
bool IsEqual(const T& left, const T& right)
{
	return left == right;
};

template<>
bool IsEqual<char*>( char* const& left,  char* const& right)
{
	return strcmp(left, right) == 0;
}

int main()
{
	cout << IsEqual<int>(22, 22) << endl;;

	return 0;
}
```

**偏特化和全特化**

```c++
#include <iostream>
using namespace std;

template<class T, class K>
class Data
{
public:
	Data()
	{
		cout << "Data<T,k>" << endl;
	}


private:
	T _d1;
	K _d2;
};

template<>
class Data<int, char>
{
public:
	Data()
	{
		cout << "Data<int,char>" << endl;
	}

private:
	int _d1;
	char _ch;
};

template<class K>
class Data<int,K>
{
public:
	Data()
	{
		cout << "Data<int,K>" << endl;
	}

private:
	int _d1;
	char _ch;
};

template<class T>
class Data<T, double>
{
public:
	Data()
	{
		cout << "Data<int,K>" << endl;
	}

private:
	int _d1;
	char _ch;
};

int main()
{
	Data<int, int> d1;
	Data<int, char> d2;
	Data<char,char> d3;

	return 0;
}
```

# 3 模板分离编译

**.h：放声明。**

**.cpp：放实现。**

**但是模板不能够分离编译。**

**1.预处理：展开头文件，删除注释，宏替换，条件编译。test.c->test.i   main.c->main.i**

**2.编译：减法语法，形成汇编代码。test.i->test.s  main.s->main.s**

**3.汇编：形成二进制代码。 test.s->test.o  main.s->main.o**

**4.链接：test.o + main.o -- a.out**
