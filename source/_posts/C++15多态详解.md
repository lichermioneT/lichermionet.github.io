# 1. 多态的概念

**多态的概念：通俗来说，就是多种形态，具体点就是去完成某个行为，当不同的对象去完成时会产生出不同 的状态**

# 2. 多态的定义及实现

**1. 必须通过基类的指针或者引用调用虚函数 **

**2. 被调用的函数必须是虚函数，且派生类必须对基类的虚函数进行重写**

```c++
#include <iostream>
#include <string>
using namespace std;

class base
{
public:
	virtual void print() const
	{
		cout << "我是基类" << endl;
	}
};

class derive : public base
{
public:
	void print() const override
	{
		cout << "我是派生类" << endl;
	}
};

void test1(const base& b)
{
	b.print();
}

void test1(const base* b)
{
	b->print();
}

int main()
{
	base b;
	derive d;

	test1(b);
	test1(d);

	base* ptr1 = new base;
	derive* ptr2 = new derive;
	test1(ptr1);
	test1(ptr2);

	return 0;
}
```

**虚函数重写的两个例外：**

**派生类重写基类虚函数时，与基类虚函数返回值类型不同。即基类虚函数返回基类对象的指针或者引 用，**

**派生类虚函数返回派生类对象的指针或者引用时，称为协变**

```c++
#include <iostream>
#include <string>
using namespace std;

class A {};
class B : public A{};

class base
{
public:
	virtual A* print() const
	{
		return new A;
	}
};

class derive : public base
{
public:
	B* print() const override
	{
		return new B;
	}
};

int main()
{

	return 0;
}
```

**析构函数的重写(基类与派生类析构函数的名字不同)**

```c++
#include <iostream>
#include <string>
using namespace std;

class A {};
class B : public A{};

class base
{
public:
	virtual ~base()
	{
		cout << "~base" << endl;
	}
};

class derive : public base
{
public:
	~derive()

		cout << "~derive" << endl;
	}
};

int main()
{
	base b;
	derive d;

	return 0;
}
```

**析构函数处理 destructor。  然后指针或者引用，指向谁调用谁。**

```c++
#include <iostream>
using namespace std;

class A
{
public:
    virtual void func(int val = 1)
    {
        std::cout << "A->" << val << std::endl;
    }

    virtual void test()
    {
        func();
    }
};

class B : public A
{
public:
    void func(int val = 0) // 继承下来，这个参数没有作用的。
    {
        std::cout << "B->" << val << std::endl;
    }
};

int main(int argc, char* argv[])
{
    B* p = new B;
    p->test();

    return 0;
}
```

**重载：同一个作用域。函数名一样，参数不一样的。**

**覆盖(重写)： c++的多态。**

**隐藏(重定义)的对比：c++继承下的，同名函数或者变量的。**

# 3. 抽象类

**抽象类：虚函数函数声明 = 0。 抽象类只是为了定义接口的。 抽象：车。**

**在虚函数的后面写上 =0 ，则这个函数为纯虚函数。包含纯虚函数的类叫做抽象类（也叫接口类），抽象类 不能实例化出对象。**

**派生类继承后也不能实例化出对象，只有重写纯虚函数，派生类才能实例化出对象。**

**纯 虚函数规范了派生类必须重写，另外纯虚函数更体现出了接口继承**

# 4.多态的原理

**虚函数：代码段。  虚函数表：代码段，常量区域。 因为虚函数的地址已经确定了的。**

```c++
#include <iostream>
#include <string>
using namespace std;

class A {};
class B : public A{};

class base
{
public:
	virtual void func1() const
	{
		cout << " base  virtual void func1() const" << endl;
	}

	virtual void func2() const
	{
		cout << " base  virtual void func2() const" << endl;
	}

	virtual ~base()
	{
		cout << "~base" << endl;
	}

	int a = 0;
};

class derive : public base
{
public:
	void func1() const override
	{
		cout << " derive  virtual void func1() const" << endl;
	}

	void func2() const override
	{
		cout << " derive  virtual void func2() const" << endl;
	}

	~derive() 
	{
		cout << "~derive" << endl;
	}

	int b = 0;
};



// 运行的时候去找指向的对象。
void func(base& d)
{
	d.func1();
	d.func2();
}

int main()
{
	// 运行时到指定对象的虚函数表，找到对应的虚函数的地址。这就是动态绑定。
	/*
		b1:vptr *func1 *func2 *base 
		    int a

		d1:vptr *func1 *func2 *derive
			int a;
			int b;
	*/

	base b1;
	derive d1; // 继承体系，虚函数表派生类也继承了的。你可以重写，也可以不重写。

	func(b1);
	func(d1);

	return 0;
}
```

# 5.单继承和多继承关系的虚函数表

**多继承**

```c++
#include <iostream>
#include <string>
using namespace std;


class base1
{
public:
	virtual void func1() const
	{
		cout << " base1  virtual void func1() const" << endl;
	}

	virtual void func2() const
	{
		cout << " base1  virtual void func2() const" << endl;
	}

	virtual ~base1()
	{
		cout << "~base" << endl;
	}

	int a = 0;  
};

class base2
{
public:
	virtual void func1() const
	{
		cout << " base2  virtual void func1() const" << endl;
	}

	virtual void func2() const
	{
		cout << " base2  virtual void func2() const" << endl;
	}

	virtual ~base2()
	{
		cout << "~base" << endl;
	}

	int a = 0;
};

// 派生类新增虚函数 f()，不会额外增加一个虚表指针，
// 而是通常将该虚函数的地址放入第一个基类对应的虚函数表中。
               // 4+4        4+4
class derive : public base1, public base2  // base1的虚函数表+变量  base2的虚函数表+变量 derive虚函数指针放在第一个后面
{
public:
	virtual int f() const  
	{
		cout << "derive" << endl;
	}
};

int main()
{
	cout << sizeof(derive) << endl;

	return 0;
}
```
