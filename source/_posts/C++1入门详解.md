# 1.命名空间

C++ 中的 **命名空间（namespace）** 主要用于解决**命名冲突**，将变量、函数、类等标识符组织到不同的作用域中。

```c++
#include <iostream>
namespace N
{
	int a = 0;
	int b = 0;
	int add(int a, int b)
	{
		return a + b;
	}

	int sub(int a, int b)
	{
		return  a - b;
	}
}

// c++ 17之前
namespace N1
{
	namespace N2
	{
		int x = 5;
	}
}

// c++ 17
namespace N1::N2
{
	int c = 0;
}

int main()
{
// 1.指定命名空间
	std::cout << N::add(1, 2) << std::endl;

// 2.引入成员
	using N::sub;
	std::cout << sub(1, 2) << std::endl;
    
// 3.全部引入
	using namespace N;
	std::cout << "a:" << a << std::endl;
	std::cout << "b:" << b << std::endl;

// 4.c++17
	std::cout << N1::N2::c << std::endl;

	return 0;
}
```

# 4.函数重载

**函数名相同，参数不同。 参数顺序不同，参数个数不同，参数顺序+参数个数都不同的。参数不同。**

**返回值没有要求的。**

```c++
#include <iostream>

#include <vector>

// _z5printstr

{
	for (const auto& e : str)
	{
		cout << e << " ";
	}

// _z5printvec

	for (const auto& e : vec)

		cout << e << " ";
```

**函数重载的原理：函数名修饰规则。**

**1预处理：头文件展开，宏替换，条件编译，去掉注释   main.cpp--main.i**

**2编译：语法检查，生成汇编代码   main.i----main.s**

**3汇编: 汇编代码转换成二进制代码  main.s----main.o**

**4链接。将目标文件连接到一起。**

**c语言不支持函数名修饰规则-----无法链接成功。**

# 5 引用

**引用给变量取别名。**

**引用的语法：类型& = 变量**

```c++
#include <iostream>
using namespace std;

int main()
{
    int a = 1;
    char ch = 'c';
    double d = 3.14;
    long long num = 4;   

    int& ref_a = a;
    char& ref_ch = ch;
    double& ref_d = d;
    long long& ref_num = num;

    const int& const_ref_a = a;
    const char& const_ref_ch = ch;
    const double& const_ref_d = d;
    const long long& const_ref_num = num;

    return 0;
}
```

**引用的特性**

```c++
#include <iostream>
using namespace std;

int add(int x, int y)
{
    return x + y;
}

int main()
{
    int a = 1;
    int b = 44;
    // 1.引用必须初始化
    int& ref_a = a;

    // 2.引用一旦初始化就不能进行修改的，这里是赋值运算的。
    ref_a = b;

    // 3.常量引用
    int c = 44;
    int& ref_c = c;  
    const int& const_ref_c = c;

    // 引用注意权限
    const int d = 44;
    const int& const_ref_d = d;

    // 4.隐士类型转换具有常属性
    int i = 55;
    const double& d_const_ref_i = i; // i:temp:d_const_ref_i; 临时变量具有常属性
    const float& f_const_ref_i = i;  // i:temp:d_const_ref_i; 临时变量具有常属性

    // 5.函数的返回值具有常属性的
    const int& ref_add = add(1, 3);
    cout << ref_add << endl;

    return 0;
}
```

```c++
#include <iostream>
using namespace std;

void Swap(int* p1, int* p2)
{
    int temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}

void Swap(int& p1, int& p2)
{
    int temp = p1;
    p1 = p2;
    p2 = temp;
}

int main()
{
    int a = 10;
    int b = 20;
    cout << "a:" << a << endl;
    cout << "b:" << b << endl;

    Swap(&a, &b);
    cout << "a:" << a << endl;
    cout << "b:" << b << endl;

    Swap(a, b);
    cout << "a:" << a << endl;
    cout << "b:" << b << endl;

    return 0;
}
```

**引用的使用场景: 做函数返回值。 注意返回值的声明周期。**

**1.减少拷贝提高效率。 2.返回引用可以进行修改数据的。**

```c++
#include <iostream>
using namespace std;

// 引用不产生拷贝
int& count1()
{
    // 全局变量，静态变量
    static int number = 10;  // 静态数据，执行一次，生命一直结束到进程结束。
    ++number;
    return number;
}

// 传值产生拷贝
int count2()
{
    // 全局变量，静态数据
    static int number = 10;  // 静态数据，执行一次，生命一直结束到进程结束。
    ++number;
    return number; // 这里返回的是一个临时变量 temp 这是一个拷贝。多开一个空间的。
}

int main()
{
    int& ref_number1 = count1();
    int& ref_number2 = count1();

    cout << ref_number1 << endl;
    cout << ref_number2 << endl;

    int number2 = count2();
    int number1 = count2();

    cout << number1 << endl;
    cout << number2 << endl;

    const int& const_ref_number1 = count2(); // 临时变量具有常属性
    const int& const_ref_number2 = count2(); // 临时变量具有常属性

    cout << const_ref_number1 << endl;
    cout << const_ref_number2 << endl;

    return 0;
}
```

**引用返回临时变量不安全的。注意返回变量的生命周期。全局变量，静态变量。**

**引用返回的好处。 1.少创建一个临时变量，提高效率。 2. 可以方便修改数据的。**



**引用和指针的区别**

```c++
1. 引用在定义时必须初始化，指针没有要求
2. 引用在初始化时引用一个实体后，就不能再引用其他实体，而指针可以在任何时候指向任何一个同类型实体
3. 没有NULL引用，但有NULL指针
4. 在sizeof中含义不同：引用结果为引用类型的大小，但指针始终是地址空间所占字节个数(32位平台下占4个字节)
5. 引用自加即引用的实体增加1，指针自加即指针向后偏移一个类型的大小
6. 有多级指针，但是没有多级引用
7. 访问实体方式不同，指针需要显式解引用，引用编译器自己处理
8. 引用比指针使用起来相对更安全

#include <iostream>
using namespace std;

int main()
{
// 1.引用的底层：也是指针实现的。
    int a = 22;
    int* p = &a;  // 开个空间：存放地址。
    int& ref_a = a; // 语法概念上：这里实际上没有开空间。
    return 0;
}
```



# 6.内联函数

**inline修饰函数。函数直接展开，不建立栈帧。小函数比较麻烦的。**

**C++用内联函数。 C语言用宏函数。**

```c++
#include <iostream>
using namespace std;

// 声明和定义不能分开。调用的地方直接展开的。
inline int add(int a, int b)
{
    return a + b;
}

int main()
{
    // 空间换时间的做法
    cout << add(1, 3) << endl;  // 这里直接展开的, 不建立栈帧
    cout << add(4, 3) << endl;  // 这里直接展开的，不建立栈帧

    return 0;
}
```

**1.main函数的栈帧   2. add函数的栈帧。**

# 7.auto

**c++11的新特性**

```c++
#include <iostream>
using namespace std;

int main()
{
    int num{ 44 };

    // 引用类型
    int& p1 = num;                 // int&
    const int& p2 = num;           // const int&
    volatile int& p3 = num;        // volatile int&
    volatile const int& p4 = num;  // const volatile int&

    // 指针类型
    int* ptr1 = &num;                  // int*
    const int* ptr2 = &num;            // const int*        （底层 const）
    volatile int* ptr3 = &num;         // volatile int*     （底层 volatile）
    volatile const int* ptr4 = &num;   // const volatile int*（底层 const volatile）

    // auto 推导（按值，丢弃顶层 cv，引用被去除）
    auto ref_p1 = p1;   // int        （p1 是 int&，auto 去引用得 int）
    auto ref_p2 = p2;   // int        （const 被丢弃，因为顶层 const）
    auto ref_p3 = p3;   // int        （volatile 被丢弃）
    auto ref_p4 = p4;   // int        （const volatile 都被丢弃）

    // auto& 推导（保留引用绑定对象的 cv）
    auto& ref_p12 = p1;   // int&
    auto& ref_p22 = p2;   // const int&
    auto& ref_p32 = p3;   // volatile int&
    auto& ref_p42 = p4;   // const volatile int&

    auto ref_ptr1 = ptr1;   // int*              （拷贝指针，值本身）
    auto ref_ptr4 = ptr2;   // const int*        （底层 const 保留）
    auto ref_ptr3 = ptr3;   // volatile int*     （底层 volatile 保留）
    auto ref_ptr44 = ptr4;  // const volatile int*（底层 cv 保留）

    // auto* 推导（显式要求指针，推导所指类型，保留底层 cv）
    auto* ref_ptr12 = ptr1;   // int*
    auto* ref_ptr22 = ptr2;   // const int*
    auto* ref_ptr32 = ptr3;   // volatile int*
    auto* ref_ptr42 = ptr4;   // const volatile int*

    return 0;
}
```

**只有指针和引用 变量的 const 和 volatil 会被保留的**

# 8.范围for

```c++
#include <iostream>

#include <list>
#include <string>
using namespace std;

{
    vector<char> v{ 'a', 'b','c','d','f' };
    list<int> ls{ 1,3,4,5,6,7,8,98,9,9,99,11 };

    for (const auto& e : v)
    {
        cout << e << " ";
    }
    cout << endl;

    for (const auto& e : ls)
    {
        cout << e << " ";
    }
    cout << endl;

    for (const auto& e : str)
    {
        cout << e << " ";
    }
    cout << endl;

    return 0;
}
```
