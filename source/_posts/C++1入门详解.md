# 1.命名空间

C++ 中的 **命名空间（namespace）** 主要用于解决**命名冲突**，将变量、函数、类等标识符组织到不同的作用域中。

```c++
#include <iostream>
namespace N
{
	int a = 0;
	int b = 0;
	int add(int a, int b)
	{
		return a + b;
	}

	int sub(int a, int b)
	{
		return  a - b;
	}
}

// c++ 17之前
namespace N1
{
	namespace N2
	{
		int x = 5;
	}
}

// c++ 17
namespace N1::N2
{
	int c = 0;
}

int main()
{
// 1.指定命名空间
	std::cout << N::add(1, 2) << std::endl;

// 2.引入成员
	using N::sub;
	std::cout << sub(1, 2) << std::endl;
    
// 3.全部引入
	using namespace N;
	std::cout << "a:" << a << std::endl;
	std::cout << "b:" << b << std::endl;

// 4.c++17
	std::cout << N1::N2::c << std::endl;

	return 0;
}
```

# 3.缺省参数

```c++
#include <iostream>
#include <string>
using namespace std;

// 1.全缺省
int add(int a = 1, int b = 2, int c = 3)
{
	return a + b + c;
}

// 2.半缺省，从右往左缺省参数
int sub(int a, int b = 2, int c = 3)
{
	return a - b - c;
}

int main()
{
	cout << "add():" << add() << endl;
	cout << "add(2):" << add(2) << endl;
	cout << "add(2,3):" << add(2,3) << endl;
	cout << "add(2,3,4,):" << add(2,3,4) << endl;

	cout << "sub(2):" << sub(2) << endl;
	cout << "sub(2,3):" << sub(2, 3) << endl;
	cout << "sub(2,3,4):" << sub(2,3,4) << endl;

	return 0;
}
```

# 4.函数重载

**函数名相同，参数不同。 参数顺序不同，参数个数不同，参数顺序+参数个数都不同的。参数不同。**

**返回值没有要求的。**

```c++
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// _z5printstr
void print(const string& str)
{
	for (const auto& e : str)
	{
		cout << e << " ";
	}
	cout << endl;
}

// _z5printvec
void print(const vector<int>& vec)
{
	for (const auto& e : vec)
	{
		cout << e << " ";
	}
	cout << endl;
}

// _z5printii
void print(int a, int b)
{
	cout << "a:" << a << endl;
	cout << "b:" << b << endl;
}

int main()
{
	string str{ "lichermionex" };
	vector<int> vec{ 1,2,4,5,6,7,78,89,44 };

	print(str);
	print(vec);
	print(1, 2);

	return 0;
}
```

**函数重载的原理：函数名修饰规则。**

**1预处理：头文件展开，宏替换，条件编译，去掉注释   main.cpp--main.i**

**2编译：语法检查，生成汇编代码   main.i----main.s**

**3汇编: 汇编代码转换成二进制代码  main.s----main.o**

**4链接。将目标文件连接到一起。**

**c语言不支持函数名修饰规则-----无法链接成功。**
