# 1. C/C++内存分布

```c++

#include <cstdlib>
using namespace std;

// ========== 1. 全局 / 静态存储区 ==========

// 已初始化数据段 .data
int globalVar = 1;
static int staticGlobalVar = 1;

// 未初始化数据段 .bss
int globalZeroVar;

void Test()
{
    // ========== 2. 静态存储区 ==========

    static int staticVar = 1;  // .data
    static int staticZero = 0; // 通常在 .bss


    // ========== 3. 栈区 Stack ==========

    int localVar = 1;             // 栈区

    int num1[10] = { 1, 2, 3, 4 }; // 数组在栈区

    char char2[] = "abcd";        // 字符数组在栈区

    // pChar3：指针变量在栈区
    // "abcd"：字符串字面量通常在只读数据段 .rodata
    const char* pChar3 = "abcd";


    // ========== 4. 堆区 Heap ==========

    // ptr1：指针变量在栈区
    // *ptr1：指向 malloc 分配的堆内存
    int* ptr1 = (int*)malloc(sizeof(int) * 4);

    // ptr2：指针变量在栈区
    // *ptr2：指向 calloc 分配的堆内存
    int* ptr2 = (int*)calloc(4, sizeof(int));

    // 分配失败检查
    if (ptr1 == nullptr || ptr2 == nullptr)
    {
        free(ptr1);
        free(ptr2);
        return;
    }

    // ptr3：指针变量在栈区
    // realloc：调整 ptr2 所指向的堆内存
    int* ptr3 = (int*)realloc(ptr2, sizeof(int) * 8);

    if (ptr3 != nullptr)
    {
        // realloc 成功，原 ptr2 指针值不能再使用
        ptr2 = ptr3;
    }

    // ========== 5. 释放堆内存 ==========

    free(ptr1);
    free(ptr2);

    // 注意：不能再 free(ptr3)
    // realloc 成功时，ptr2 和 ptr3 指向同一块内存
}

int main()
{
    Test();
    return 0;
}
```

**1. 栈又叫堆栈，非静态局部变量/函数参数/返回值等等，栈是向下增长的。 **

**2. 内存映射段是高效的I/O映射方式，用于装载一个共享的动态内存库。用户可使用系统接口创建共享共 享内存，做进程间通信。**

**3. 堆用于程序运行时动态内存分配，堆是可以上增长的。 **

**4. 数据段--存储全局数据和静态数据。 **

**5. 代码段--可执行的代码/只读常量。**

# 3. C++内存管理方式

```c++
#include <iostream>
#include <cstdlib>
using namespace std;

int main()
{
// c++的new是操作符

// 基本的数据类型，没有区别的。
    int* p1 = new int; // 不初始化
    int* p2 = new int(33); // 初始化
    int* p3 = new int{ 44 }; // 初始化
    int* p4 = new int[10]{0 }; // 初始化

    int* p5 = (int*)malloc(sizeof(int));
    int* p6 = (int*)malloc(sizeof(int));
    int* p7 = (int*)malloc(sizeof(int));

    delete p2;
    delete p3;

    free(p5);
    free(p6);
    free(p7);
    free(p8);

```

# 4. operator new与operator delete函数

**new和delete是用户进行动态内存申请和释放的操作符，**

**operator new 和operator delete是系统提供的 全局函数，**

**new在底层调用operator new全局函数来申请空间，**

**delete在底层通过operator delete全局 函数来释放空间。**

**operator new 实际也是通过malloc来申请空间，如果malloc申请空间 成功就直接返回，否则执行用户提供的空间不足应对措施，如果用户提供该措施就继续申请，否则就抛异常。**

**operator delete 最终是通过free来释放空间的**

**C++的原则：获取就初始化，离开就析构。**

```c++
#include <iostream>
#include <cstdlib>
using namespace std;

int main()
{
    size_t size = 400;
    void* p1 = malloc(size * 1024 * 1024 * 1202);
    cout << p1 << endl;  // 失败返回 NULL

    try
    {
        void* p2 = operator new(size * 1024 * 1024 * 1202); // 抛出异常
    }
    catch (exception& e)
    {
        cout << e.what() << endl;
    }

    //operator delete(p2);

    return 0;
}
```

# 5. new和delete的实现原理

## 5.1 内置类型

**如果申请的是内置类型的空间，new和malloc，delete和free基本类似，**

**不同的地方是：new/delete申请和 释放的是单个元素的空间，new[]和delete[]申请的是连续空间，**

**而且new在申请空间失败时会抛异常， malloc会返回NULL。**



## 5.2 自定义类型

**new的原理 \1. 调用operator new函数申请空间    \2. 在申请的空间上执行构造函数，完成对象的构造**

**delete的原理 \1. 在空间上执行析构函数，完成对象中资源的清理工作 \2. 调用operator delete函数释放对象的空间 **

**new T[N]的原理**

​	**\1. 调用operator new[]函数，在operator new[]中实际调用operator new函数完成N个对象空间的申 请**

​	**\2. 在申请的空间上执行N次构造函数**

**delete[]的原理**

​	**\1. 在释放的对象空间上执行N次析构函数，完成N个对象中资源的清理**

​	**\2. 调用operator delete[]释放空间，实际在operator delete[]中调用operator delete来释放空间**

# 6. 定位new表达式(placement-new)

**定位 new 是 C++ 中一种特殊的** `new` **表达式，它可以在已经分配好的内存上构造对象，而不再重新分配内存。**

```c++
#include <iostream>
#include <new>
#include <cstdlib>
using namespace std;

class Test
{
public:
    Test(int x) : _x(x)
    {
        cout << "构造函数" << endl;
    }

    ~Test()
    {
        cout << "析构函数" << endl;
    }

private:
    int _x;
};

int main()
{
    // 1. 分配原始内存，不调用构造函数
    void* ptr = malloc(sizeof(Test));

    if (ptr == nullptr)
        return 1;

    // 2. 定位new：在指定内存上构造对象
    Test* obj = new (ptr) Test(10);

    // 3. 手动调用析构函数
    obj->~Test();

    // 4. 释放原始内存
    free(ptr);

    return 0;
}
```



# 7. 常见面试题

**malloc/free和new/delete的共同点是：都是从堆上申请空间，并且需要用户手动释放。不同的地方是：** 

1. **malloc和free是函数，new和delete是操作符** 
2. **malloc申请的空间不会初始化，new可以初始化** 
3. **malloc申请空间时，需要手动计算空间大小并传递，new只需在其后跟上空间的类型即可** 
4. **malloc的返回值为void*, 在使用时必须强转，new不需要，因为new后跟的是空间的类型**
5. **malloc申请空间失败时，返回的是NULL，因此使用时必须判空，new不需要，但是new需要捕获异常** 
6. **申请自定义类型对象时，malloc/free只会开辟空间，不会调用构造函数与析构函数，而new在申请空间 后会调用构造函数完成对象的初始化，delete在释放空间前会调用析构函数完成空间中资源的清理**
