# 1. 再谈构造函数

**初始化列表：初始引用，常量，没有默认构造函数的对象。**

**1. 每个成员变量在初始化列表中只能出现一次(初始化只能初始化一次)**

**2. 类中包含以下成员，必须放在初始化列表位置进行初始化： 引用成员变量 const成员变量: 自定义类型成员(该类没有默认构造函数**

**3.尽量使用初始化列表初始化，因为不管你是否使用初始化列表，对于自定义类型成员变量，一定会先使 用初始化列表初始化。**

**4.成员变量在类中声明次序就是其在初始化列表中的初始化顺序，与其在初始化列表中的先后次序无关**

```c++
#include <iostream>
using namespace std;

class obj
{
public:
	obj(int a, int b)
		:_a(a)
		,_b(b)
	{ }
private:
	int _a;
	int _b;
};

class test
{
public:
	test(int number, int& ref, int a, int b)
		:_number(number)  // 初始化列才是定义
		,_ref_int(ref)    // 初始化列才是定义
		,_ret(a,b)        // 初始化列才是定义
	{ 
		// 构造函数里面就是赋值
	}

private:
	const int _number;  // 这是声明
	int& _ref_int;      // 这是声明
	obj _ret;           // 这是声明
};

int main()
{
	int a = 44;
	int& ref = a;

	test t1(22, a, 4, 5);
	test t(222, ref, 4, 5);

	return 0;
}
```

# 2. static成员

**静态成员属性**

**静态成员方法**

**统计一个类，到底实例化了多少的对象。**

```c++
#include <iostream>
using namespace std;

class obj
{
public:
	obj()
	{
		count++;
	}

	obj(const obj& ret)
	{
		count++;
	}

	void print()
	{
		cout << "count:" << count << endl;
	}

	// 静态函数没有this指针。
	static int getN()
	{
		return count; // 静态函数可以访问静态属性
	}

private:
	static int count;  // 静态属性：属于对象。 这是声明
};

// 静态成员类外初始化
int obj::count = 0;

int main()
{
	obj ret[100002];

	ret[1].print();
	cout << obj::getN() << endl; // 没有this指针，可以直接调用。

	return 0;
}
```

**非静态可以调用-------静态**

**静态不可以调用----非静态**  **突破类域就行了的。**

```c++
#include <iostream>

{
public:

	{
		_sum += _i;

	static int GetSum()

	cout << st.Solution(4) << endl;

}
```

# 4. 友元

**友元函数，可以访问对象的属性和方法，破坏了类的封装，但是也带来了便利。**

```c++
#include <iostream>
using namespace std;

class Obj
{
    // 友元函数的声明
	friend ostream& operator<<(ostream& out, const Obj& obj);
	friend istream& operator>>(istream& in, Obj& obj);
public:
	Obj(int a, int b, int c)
		:_a(a)
		,_b(b)
		,_c(c)
	{ }

private:
	int _a;
	int _b;
	int _c;
};

// 友元函数可以访问类的属性和方法。
ostream& operator<<(ostream& out, const Obj& obj)
{
	out << obj._a << "-" << obj._b << "-" << obj._c << endl;

	return out;
}

istream& operator>>(istream& in, Obj& obj)
{
	in >> obj._a;
	in >> obj._b;
	in >> obj._c;

	return in;
}

int main()
{
	Obj ret1(1, 2, 3);
	Obj ret2(4, 5, 6);
	Obj ret3(7, 8, 9);
	cout << ret1 << ret2 << ret3 <<endl;

	cin >> ret1;

	cout << ret1 << endl;

	return 0;
}
```
