# 般若波罗蜜多心经

唐 · 玄奘译　｜　[古文岛原文](https://www.guwendao.net/guwen/bookv_b7ae953db0d4.aspx)

通称《心经》。题中的“心”有核心、精要之意。以下依原网页的五个自然段排印，小标题、白话串讲、词注和段评为本次整理所加。

## 照见五蕴

<div style="box-sizing:border-box;background-color:#f0efe2;padding:8px 14px;overflow-wrap:anywhere;">


<p title="原文" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:0;"><font color="#0f0f0f">观自在菩萨，行深般若波罗蜜多时，照见五蕴皆空，度一切苦厄。</font></p>

<p title="白话串讲" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#518564;margin:6px 0 0;"><font color="#518564">观自在菩萨深入修习般若智慧的时候，看清了构成身心的五蕴都依种种条件而起，没有哪一蕴能独立自存。凭这样的观照，菩萨得以渡过一切苦难。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:6px 0 0;"><font color="#af9100">观自在菩萨，即观世音菩萨。般若（bō rě），指洞察事物实相的智慧。波罗蜜多，常译作“到彼岸”，也有圆满成就之意。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:0;"><font color="#af9100">五蕴，是佛教分析身心经验的五类。色指身体等物质现象，受指苦、乐等感受，想指辨认事物的形象与特征，行包括意志、造作等活动，识指对所缘对象的了别。</font></p>

<blockquote title="段评" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:6px 0 0;background-color:#e9e8dc;border:0;border-radius:2px;margin:12px 0 4px;padding:10px 15px;"><font color="#0f0f0f">开头的“行”“照见”“度”写出修习、看清与渡过的次序。后面解释“空”的句子，都可以回过头来对照这里所说的苦。</font></blockquote>

</div>

## 色与空

<div style="box-sizing:border-box;background-color:#f0efe2;padding:8px 14px;overflow-wrap:anywhere;">


<p title="原文" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:0;"><font color="#0f0f0f">舍利子，色不异空，空不异色，色即是空，空即是色，受想行识亦复如是。</font></p>

<p title="白话串讲" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#518564;margin:6px 0 0;"><font color="#518564">舍利子，形体与物质现象都依条件而有，这便是说色无自性。所谓空，也就在这些具体的现象之中。感受、辨认、意志活动和识别，同样都依条件而起。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:6px 0 0;"><font color="#af9100">舍利子，又称舍利弗，是佛陀的弟子。经中两次呼唤他的名字，以下都是对他说的话。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:0;"><font color="#af9100">空，指事物没有独立、恒定的自性。</font></p>

<blockquote title="段评" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:6px 0 0;background-color:#e9e8dc;border:0;border-radius:2px;margin:12px 0 4px;padding:10px 15px;"><font color="#0f0f0f">经文先从“色”说到“空”，随即又从“空”说回“色”。譬如眼前的花，离开种子、水土和生长过程，哪里能找到一朵独立自成的花？</font></blockquote>

</div>

## 无所得与无挂碍

<div style="box-sizing:border-box;background-color:#f0efe2;padding:8px 14px;overflow-wrap:anywhere;">


<p title="原文" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:0;"><font color="#0f0f0f">舍利子，是诸法空相，不生不灭，不垢不净，不增不减。是故空中无色，无受想行识，无眼耳鼻舌身意，无色声香味触法，无眼界乃至无意识界，无无明亦无无明尽，乃至无老死，亦无老死尽，无苦集灭道，无智亦无得，以无所得故。菩提萨埵，依般若波罗蜜多故，心无挂碍；无挂碍故，无有恐怖，远离颠倒梦想，究竟涅槃。</font></p>

<p title="白话串讲" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#518564;margin:6px 0 0;"><font color="#518564">舍利子，从诸法的空性来看，生与灭、染污与清净、增多与减少，都不能被认定为诸法自身固定的属性。以这种眼光看，五蕴、眼、耳等六根，六根所对的境，以及由此生起的种种识，都找不到独立不变的自性。</font></p>

<p title="白话串讲" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#518564;margin:0;"><font color="#518564">从无明到老死，无论说这些因缘如何生起，还是说它们如何止息，道理也一样。苦、苦的成因、苦的止息、通往止息的道路，乃至修行的智慧和所证的成果，也都不可执取。菩萨依般若而行，无所得，心便没有挂碍。心无挂碍，便无所恐惧，远离颠倒迷妄，究竟解脱。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:6px 0 0;"><font color="#af9100">六根、六境、六识。以耳为例，耳是根，声音是境，听到声音时生起耳识。眼、耳、鼻、舌、身、意各有相应的境与识，合称十八界。“乃至”表示中间各项从略。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:0;"><font color="#af9100">无明，指对事理的根本迷惑。经文以“无明”和“老死”举出十二因缘的首尾。“无明尽”“老死尽”的“尽”是止息。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:0;"><font color="#af9100">苦、集、灭、道合称四谛。菩提萨埵是“菩萨”的全称。涅槃指烦恼止息的解脱。</font></p>

<blockquote title="段评" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:6px 0 0;background-color:#e9e8dc;border:0;border-radius:2px;margin:12px 0 4px;padding:10px 15px;"><font color="#0f0f0f">读这一长段，可以从末尾回看那一连串“无”：就连用来理解苦的教法，也没有一样可以据为己有。经文随后写到的变化，落在心中少了什么牵挂、什么恐惧。</font></blockquote>

</div>

## 三世诸佛与般若

<div style="box-sizing:border-box;background-color:#f0efe2;padding:8px 14px;overflow-wrap:anywhere;">


<p title="原文" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:0;"><font color="#0f0f0f">三世诸佛，依般若波罗蜜多故，得阿耨多罗三藐三菩提。故知般若波罗蜜多，是大神咒，是大明咒，是无上咒，是无等等咒，能除一切苦，真实不虚。</font></p>

<p title="白话串讲" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#518564;margin:6px 0 0;"><font color="#518564">过去、现在、未来的一切佛，都依般若智慧而成就无上正等正觉。因此，经文用四个称号赞叹般若，说它有不可思议的力量，能破除蒙昧，无上而无可比拟，能够解除一切苦，这话真实不虚。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:6px 0 0;"><font color="#af9100">三世，即过去、现在、未来。阿耨多罗三藐三菩提，是梵语音译，通常意译为“无上正等正觉”。无等等，没有什么可以与之相比。</font></p>

<blockquote title="段评" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:6px 0 0;background-color:#e9e8dc;border:0;border-radius:2px;margin:12px 0 4px;padding:10px 15px;"><font color="#0f0f0f">上一段说“无所得”，这里却说诸佛“得”觉悟。把两个“得”连起来读：觉悟可以成就，却无法像一件属于自己的东西那样被占有。</font></blockquote>

</div>

## 般若心咒

<div style="box-sizing:border-box;background-color:#f0efe2;padding:8px 14px;overflow-wrap:anywhere;">


<p title="原文" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:0;"><font color="#0f0f0f">故说般若波罗蜜多咒，即说咒曰：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃。</font></p>

<p title="白话串讲" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#518564;margin:6px 0 0;"><font color="#518564">于是，经文宣说般若波罗蜜多咒，以一段音译的咒语收束全经。依传统的一种释读，反复的“揭谛”可领会为“去、渡”，随后说到彼岸、一同渡到彼岸，以觉悟与成就作结。</font></p>

<p title="词注" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#af9100;margin:6px 0 0;"><font color="#af9100">揭谛等字在这里用来记音。法藏《般若波罗蜜多心经略疏》既记诵持原音的传统，也列出解释咒义的一种读法。“菩提”意为觉悟。</font></p>

<blockquote title="段评" style="font-family:'Microsoft YaHei','PingFang SC',sans-serif;font-size:16px;font-weight:400;line-height:2;text-indent:2em;text-align:justify;color:#0f0f0f;margin:6px 0 0;background-color:#e9e8dc;border:0;border-radius:2px;margin:12px 0 4px;padding:10px 15px;"><font color="#0f0f0f">开头用一个“度”字写菩萨渡过苦厄，结尾以反复的咒音收束。沿着“渡到彼岸”的读法重读，首尾便有了呼应。</font></blockquote>

</div>
