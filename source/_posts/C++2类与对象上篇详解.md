# 1.从面向过程到面向对象

**C语言是面向过程的，关注的是过程，分析出求解问题的步骤，通过函数调用逐步解决问题。  面向过程：函数。** 

**C++是基于面向对象的，关注的是对象，将一件事情拆分成不同的对象，靠对象之间的交互完成。 面向对象：类和对象。**

# 2.类的引入

**C语言中，结构体中只能定义变量。在C++中，结构体内不仅可以定义变量，也可以定义函数。**

**完事万物都是对象，对象都具有自己特定的属性和方法。**

```c++
#include <iostream>
#include <cstring>
using namespace std;

struct Student
{
    void SetStudentInfo(const char* name, const char* gender, int age)
    {
        strcpy(_name, name);
        strcpy(_gender, gender);
        _age = age;
    }

    void PrintStudentInfo()
    {
        cout << _name << " " << _gender << " " << _age << endl;
    }

    char _name[20];
    char _gender[3];
    int _age;
};

int main()
{
    Student s;
    s.SetStudentInfo("Peter", "男", 18);
    return 0;
}
```

# 3.类的定义

```c++
#include <iostream>
using namespace std;

class person
{
public:
	int a = 10; // 成员属性
	void print()
	{
		cout << "a:" << a << endl;  // 成员方法
	}

protected:
	int b = 10; // 成员属性

private:
	int c = 10; // 成员属性
};

int main()
{
	return 0;
}
```

**c++ 可以用class和struct进行定义类。  struct默认访问权限是公有的，兼容c语言。  class默认访问权限是私有的。**

**1、C语言中struct是用来定义结构体的**

**2、C++中，兼容C的struct定义结构体的用法。但是同时struct也可以用来定义类**

**3、C++中使用class和struct定义类的区别?-》默认的访问限定符**

**4、C++可以直接用类名使用，不需要带关键字 class 或者  struct**

# 4.访问限定符

**public:外面可看到，也可以继承下去。继承下去看得到。**

**protected:外面不可看到，能够被继承下去的。继续下去看得到。**

**private: 外面不可看到，能够被继承下去的。继承下去也看不到的。**

**封装----继承----多态**

# 5.类的作用域

**类定义了一个新的作用域，类的所有成员属性，成员方法都在类的作用域中。在类体外定义成员，需要使用 :: 作用域解析符 指明成员属于哪个类域。**

**静态属性初始化，或者成员属性方法实现的的时候   需要域名解析。**

```c++
#include <iostream>
using namespace std;

class person
{
public:
	int a = 10; // 成员属性
	void print()
	{
		cout << "a:" << a << endl;  // 成员方法
	}

protected:
	int b = 10; // 成员属性

private:
	int c = 10; // 成员属性
	static  int c;
};
// 域名解析符
int person::c = 44;

int main()
{
	return 0;
}
```

# 7.类对象模型

1. **非静态成员变量占用对象内存**，普通成员函数不占用每个对象的内存。
2. **静态成员变量不计入类对象大小**。
3. **空类的大小通常是 1 字节**，标准要求完整的不同空类对象具有不同地址。
4. **存在虚函数的类通常会有虚函数表指针（vptr）**，常见 64 位平台上指针为 8 字节。
5. **需要考虑内存对齐和填充**，类的总大小通常是其对齐要求的整数倍

```c++
#include <iostream>
using namespace std;

class person
{
public:
	int a = 10; // 成员属性
	void print()
	{
		cout << "a:" << a << endl;  // 成员方法
	}

protected:
	int b = 10; // 成员属性

private:
	int z = 10; // 成员属性
	static int c; // 静态属性属于类
};

int main()
{
	cout << sizeof(person) << endl; // 12

	return 0;
}
```

**空对象默认是一个字节，用来占位置。需要取地址。用来站位表示对象存在的。**

# 8.this指针

**类的成员属性都是一个逻辑，处理的对象一样，只需要包含隐士的this指针就行了的。**

**const成员函数默认的const指针。**

```c++
#include <iostream>
using namespace std;

class Date
{
public:
	// void Display(date* this)
	void Display() const // void Display(date* this) 
	{
		cout << this->_year << "-" << this->_month << "-" << this->_day << endl;
	}

	// void SetDate(date* this,int year, int month, int day) 
	void SetDate(int year, int month, int day) 
	{
		this->_year = year;
		this->_month = month;
		this->_day = day;
	}
private:
	int _year = 0; // 年
	int _month = 1; // 月
	int _day = 1; // 日
};
int main()
{
	// 谁调用就把自己的地址传递给函数。
	Date d1, d2;
	d1.SetDate(2018, 5, 1); // d1.SetDate(&d1, 2018, 5, 1); d1的指针
	d2.SetDate(2018, 7, 1); // d2.SetDate(&d2, 2018, 5, 1); d2的指针
	d1.Display();           // d1.Display(&d1); d1的指针
	d2.Display();           // d2.Display(&d2); d2的指针

	const Date d3, d4;      // 只能够调用const成员函数
	d3.Display();           // d3.Display(const &d3); d3的指针
	d4.Display();           // d4.Display(const &d4); d4的指针

	return 0;
}
```

**隐含的this指针。  静态属性没有this指针的。**

**this指针存在进程的那个区域呢？  栈区---函数的形式参数。  vs存在ecx寄存器里面的。**
